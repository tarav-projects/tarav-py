## Skillware POIs keep their identity

The User noticed that a Skillware POI's situation carried `surface_state`, the
content hashes of every file of its skill package. Because a POI's identity
is its Type and situation, any edit to the package gave every open Skillware
problem a new identity: the action store held 116 actions for 43 problems,
110 of them closed as gone. The state now lives in the POI's details, with
Project-relative paths, and Skillware POIs pin it: a blessing reopens when
the package changes after it, so an acceptance still cannot float across
edits. Request 925.
