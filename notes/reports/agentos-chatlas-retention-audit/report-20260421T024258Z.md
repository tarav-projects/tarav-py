## Current recommendation

### Raw archive required

- `.claude/projects/**/*.jsonl`: primary CLI-side Claude session transcripts. These contain user turns, assistant turns, tool use/result events, progress records, and inline usage metadata.
- `.claude/archive/**/*.jsonl`: archived Claude session transcripts that are still first-class raw conversation artifacts.
- `Library/Application Support/Claude/claude-code-sessions/**/*.json`: desktop-side Claude Code session artifacts. Required because they are real transcript-bearing session files and currently contribute extractable sessions.

### Raw archive optional future

- `.claude/usage-data/session-meta/*.json`: low-volume per-session telemetry summaries linked by `session_id`; useful for later usage study and behavioral analysis, but not required for transcript reconstruction.
- `.claude/usage-data/facets/*.json`: low-volume derived session summaries such as goal/outcome/friction labels; useful for future study, but not required for raw transcript fidelity.
- `.claude/settings.json`: user-visible Claude configuration affecting permissions, hooks, model defaults, plugins, and editor behavior. Useful behavioral context for later session interpretation.
- `.claude/CLAUDE.md`: local instruction/memory policy document that can materially affect Claude behavior in the home environment.
- `.claude/tasks/**/[0-9]*.json`: a small number of structured task-plan JSON files that preserve model workflow/checkpoint intent.
- `.claude/todos/*.json`: optional only. A few files contain useful task checklists, but most are empty placeholder arrays.
- `projects/**/sessions-index.json`: optional session-index metadata for project roots.

### Telemetry outside session scope

- `.claude/stats-cache.json`: aggregate daily activity counters. Useful telemetry, but not session raw.
- `.claude/telemetry/**`: large product-analytics/event backlog. If account-usage or product telemetry study is needed later, this should be handled as a dedicated telemetry surface rather than raw session archive.

### Exclude

- `.claude/file-history/**`: copied file-version residue. It can contain arbitrary workspace content and is not needed for raw chat reconstruction.
- `.claude/backups/**`: rotating local backup copies of Claude state files. Redundant and noisy.
- `.claude/history.jsonl`: prompt-history index. It duplicates user prompt evidence already preserved in session transcripts and is not needed for transcript fidelity.
- `.claude/debug/**`: runtime diagnostics, not primary session evidence.
- `.claude/sessions/*.json`: legacy PID/session metadata files. These are lightweight runtime records, not transcripts, and the committed raw archive currently contains many stale copies.
- `.claude/tasks/**/*.lock`
- `.claude/tasks/**/.highwatermark`
- `.claude/mcp-needs-auth-cache.json`: auth-adjacent cache of MCP auth requirements.
- `.claude/plugins/**`: local plugin installation/cache state, not chat-session evidence.
- `.claude/hooks/**`
- `.claude/statusline`
- `.claude/statusline.dump`
- `.claude/.example-claude-statusline.json`
- `Library/Application Support/Claude/config.json`: includes `oauth:tokenCache`; should not be archived.
- `Library/Application Support/Claude/claude_desktop_config.json`
- `Library/Application Support/Claude/git-worktrees.json`
- `Library/Application Support/Claude/extensions-blocklist.json`
- `Library/Application Support/Claude/window-state.json`
