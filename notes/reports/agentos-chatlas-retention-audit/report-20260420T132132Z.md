## Current recommendation

### Raw archive required

- `session-state/**/events.jsonl`: primary session evidence; contains user input, visible assistant output, tool execution events, reasoning events when present, session boundaries, and shutdown usage metrics
- `session-state/*.jsonl`: legacy flat session event artifacts; required for older retained Copilot sessions that do not use per-session directories
- `session-state/**/files/**`: low-volume session artifacts that can hold user-provided inputs, generated assets, or intermediate files referenced by the session; excluding them risks losing context not embedded in the event stream

### Raw archive optional future

- `session-state/**/plan.md`: low-volume behavior artifacts that capture explicit agent planning outside the visible transcript
- `session-state/**/checkpoints/*.md` excluding `session-state/**/checkpoints/index.md`: rare checkpoint note files with substantive intermediate state
- `copilot-instructions.md`: one cheap global behavior-shaping file; optional if Chatlas wants minimal environment context alongside the session corpus

### Telemetry outside session scope

- none observed today; session-level usage telemetry is already present inside `events.jsonl` `session.shutdown` records, and no distinct quota/billing/usage file family was found under `~/.copilot`

### Exclude

- `session-state/**/workspace.yaml`: high file-count overhead with low incremental corpus value; mostly cwd, timestamps, and summary metadata already covered or reproducible elsewhere
- `session-state/**/checkpoints/index.md`: mostly empty or derived index files; duplicates checkpoint existence with heavy file-count cost
- `session-state/**/vscode.metadata.json`: near-empty editor residue with no meaningful session evidence
- `session-state/**/session.db`: opaque binary sidecar with no proven unique corpus value
- `session-state/**/rewind-snapshots/**`: copied workspace/backups rather than primary chat evidence
- `session-state/**/*.lock`: runtime residue
- `command-history-state.json`: cross-session command history that mixes unrelated and possibly aborted user inputs; privacy-heavy and not session-bound
- `config.json`: global local-path/account settings with weak session value
- existing non-session bulk excludes remain correct: `logs/`, `pkg/`, and `ide/`
