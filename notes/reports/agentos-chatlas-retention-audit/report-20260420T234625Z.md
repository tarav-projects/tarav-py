## Current recommendation

### Raw archive required

- `session-state/**/events.jsonl`: primary Copilot session event stream; retains visible user input, visible assistant output, tool activity, reasoning signals when emitted, session boundaries, and per-session usage metrics.
- `session-state/*.jsonl`: legacy flat Copilot session event stream; required for older retained sessions that do not use per-session directories.
- `session-state/**/files/**`: sparse session artifacts and attachments; retain until Copilot file semantics are better classified because they can carry user-relevant inputs or outputs not fully embedded in the event stream.

### Raw archive optional future

- `session-state/**/plan.md`: low-volume agent planning evidence useful for behavioral analysis.
- `session-state/**/checkpoints/*.md` except `session-state/**/checkpoints/index.md`: substantive checkpoint or compaction notes useful for behavioral analysis.
- `copilot-instructions.md`: cheap global behavior-shaping context; retain the dereferenced file content. If the live provider-home path is a symlink, Chatlas raw should follow it and archive a regular file, not symlink identity.

### Telemetry outside session scope

- No distinct Copilot quota, billing, or account-limit raw file family was found under `/Users/pereiro/.copilot`.
- Session-level telemetry remains inside `events.jsonl`, especially shutdown and model-metric records.

### Exclude

- `session-state/**/workspace.yaml`: high-count summary/cwd metadata with low incremental raw value.
- `session-state/**/checkpoints/index.md`: derived or near-empty checkpoint index files.
- `session-state/**/vscode.metadata.json`: editor residue, usually empty.
- `session-state/**/session.db`: opaque binary sidecar with no demonstrated unique raw corpus value.
- `session-state/**/rewind-snapshots/**`: copied workspace/rewind state, not primary chat evidence.
- `session-state/**/*.lock`: runtime lock residue.
- `command-history-state.json`: cross-session command history with privacy-heavy non-session spillover.
- `config.json`: local account/path settings with weak session value.
- Bulk runtime/package/editor directories remain excluded: `pkg/`, `logs/`, `ide/`.
