## Current recommendation

### Raw archive required

- `sessions/**/*.jsonl`: retain raw Codex rollout files as the primary transcript and tool-behavior source
- `archived_sessions/**/*.jsonl`: retain archived rollout files with the same priority as active sessions
- `session_index.jsonl`: retain raw session index metadata when present to preserve thread names and visible session inventory

### Raw archive optional future

- `history.jsonl`: retain only if Chatlas wants prompt-history recovery beyond the rollout corpus
- `AGENTS.md`: retain only if Chatlas wants home-level behavior context that may shape sessions
- `rules/*.rules`: retain only if Chatlas wants Codex approval-policy and command-guardrail context

### Telemetry outside session scope

- `version.json`: useful for version-drift and update-history study, but not part of the session raw corpus
- `installation_id`: useful only for account/install telemetry and should stay out of the raw session archive

### Exclude

- `auth.json`, `_auth*.json`: secret-bearing auth state
- `config.toml`: trusted-path and auth-mode configuration, not session-native evidence
- `logs_2.sqlite*`, `state_5.sqlite*`, `sqlite/**`: runtime databases and write-ahead files
- `log/**`: UI/runtime logs
- `shell_snapshots/**`: copied shell context, not session-native transcript evidence
- `.tmp/**`, `tmp/**`, `cache/**`, `models_cache.json`: caches and transient staging
- `skills/**`, `plugins/**`, `worktrees/**`, `.codex/**`: local package/runtime surfaces and nested home residue
- `memories/**`, `.personality_migration`: local runtime state with little archival value
- `version.json`, `installation_id`: exclude from the session raw corpus even if tracked separately as telemetry
